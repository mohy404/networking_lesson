HTTP مقابل HTTPS

🔓

HTTP

  • HTTP نفسه مش بيشفّر البيانات.
  • البورت الافتراضي: 80.
  • لو حد بيراقب الشبكة ممكن يقرا البيانات.
password=1234
🔒

HTTPS

  • HTTP فوق TLS: اتصال مشفّر.
  • حماية سلامة البيانات (Integrity).
  • التحقق من هوية السيرفر بالشهادات (Certificates).
  • البورت الافتراضي: 443.
x9$#kQ2@!ZpL
انتبه: HTTPS مش معناه إن الموقع آمن أو موثوق 100%. موقع ممكن يستخدم HTTPS وفيه ثغرات زي SQL Injection أو XSS أو Broken Access Control، أو يكون موقع احتيال بشهادة سليمة. القفل بيأمّن «الطريق» مش «الموقع نفسه».
